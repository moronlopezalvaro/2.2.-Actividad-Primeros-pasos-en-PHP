# 2.2.-Actividad: Primeros pasos en PHP

## Resumen de la actividad

En esta actividad se ha trabajado con los conceptos básicos de PHP para crear una página dinámica y funcional. El objetivo principal era practicar la configuración inicial del lenguaje, la definición de variables, el uso de funciones y el manejo de ámbitos de variables en PHP.

## Qué se ha realizado

- Se configuró PHP para mostrar errores y depurar el código con `ini_set()` y `error_reporting()`.
- Se definieron variables para almacenar el nombre, apellidos y edad actual del usuario.
- Se utilizó una función llamada `calcularEdadesFuturas()` para calcular:
  - la edad dentro de 10 años,
  - la edad dentro de 20 años,
  - el doble de la edad actual.
- Se aplicó el uso de variables globales mediante la palabra reservada `global` para modificar datos desde una función.
- Se mostró la fecha y hora actual del sistema con `date()` para dar dinamismo a la página.
- Se integró PHP con HTML y JavaScript para crear una pequeña interfaz en la que el usuario pulsa botones y obtiene resultados sin recargar la página.
- Se implementó un texto dinámico con mensajes como “Dentro de 10 años tendré …” y “El doble de mi edad es …”.

## Resultado final

Se ha creado una pequeña web en PHP que presenta una identificación personal y permite calcular proyecciones de edad de forma automática y visualmente atractiva. La práctica combina programación del lado del servidor con interactividad en el cliente, mostrando una introducción clara a los fundamentos del lenguaje PHP.
